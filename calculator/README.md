# Rozwiązanie – Kalkulator i aplikacja webowa

W tym katalogu znajduje się rozwiązanie laboratorium obejmujące implementację kalkulatora oraz aplikacji webowej.

W pierwszej części zaimplementowana została klasa kalkulatora, która odpowiada za wykonywanie podstawowych operacji matematycznych.

Następnie przygotowana została prostą aplikacja webową, która wykorzystuje wcześniej zaimplementowaną klasę kalkulatora. Dzięki temu logika obliczeniowa nie jest implementowana dwukrotnie DRY (Don't Repeat Yourself), lecz współdzielona pomiędzy poszczególnymi częściami projektu.

Przygotowane zostały także testy jednostkowe.
