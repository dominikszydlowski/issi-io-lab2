# Rozwiązanie – Kalkulator i aplikacja webowa

W tym katalogu znajduje się rozwiązanie laboratorium obejmujące implementację kalkulatora oraz aplikacji webowej.

W pierwszej części zaimplementowałem klasę kalkulatora, która odpowiada za wykonywanie podstawowych operacji matematycznych.

Następnie przygotowałem prostą aplikację webową, która wykorzystuje wcześniej zaimplementowaną klasę kalkulatora. Dzięki temu logika obliczeniowa nie jest implementowana dwukrotnie DRY (Don't Repeat Yourself), lecz współdzielona pomiędzy poszczególnymi częściami projektu.

Przygotowałem także testy jednostkowe.
